## What you need

- **Gemini or ChatGPT** — Free. Writes the script and the image prompts.
- **ElevenLabs** — Free plan has monthly credits for voice. Using it on a monetised channel needs a paid plan — check their pricing.
- **Meta AI** — Free image generator; its Animate option turns a picture into a short clip (not available in every country).
- **YouTube Create app** — Free Android editor from YouTube with auto captions and music.

## Step by step

### Step 1: Write the script with image prompts

Paste this in Gemini or ChatGPT. You get the voice script and a matching picture prompt for every line.

![Write the script with image prompts — Write a 40-second YouTube Shorts script for a faceless channel, with image prompts → You get](/images/guides/faceless-youtube-shorts-with-free-ai-script-to-upload/step-1.svg)

**Prompt · step 1**

```text
Write a 40-second YouTube Shorts script for a faceless channel about {niche}.
Topic: {topic}. Language: {lang}.

Rules:
- Line 1 is the hook and must make people stop scrolling in 2 seconds.
- 8 to 10 short lines, one idea per line.
- End with a question that makes people comment.
- Under each line, write an image prompt in {style} style, vertical 9:16, no text in the image.
Give it as a table: line | voice text | image prompt.
```

### Step 2: Make the voice

In ElevenLabs → Text to Speech, pick a voice that fits your niche, paste only the voice text, generate and download the MP3. Keep the same voice for every video — it becomes your channel's identity.

![Make the voice — ElevenLabs · Text to Speech: Pick a voice → voice.mp3](/images/guides/faceless-youtube-shorts-with-free-ai-script-to-upload/step-2.svg)

### Step 3: Make the visuals

In Meta AI, paste each image prompt one by one. When you like a picture, tap Animate to turn it into a short moving clip. Download all clips in order.

![Make the visuals — Rewrite these image prompts so the same main character looks identical in every picture → One picture per line](/images/guides/faceless-youtube-shorts-with-free-ai-script-to-upload/step-3.svg)

**Prompt · step 3**

```text
Rewrite these image prompts so the same main character looks identical in every picture (same face, clothes and colours). Keep {style} style, 9:16, no text: [paste your prompts]
```

### Step 4: Edit in YouTube Create

New project → add clips in order → add your MP3 → trim each clip to match its line → Captions → auto captions → fix any wrong words → add low background music from the app's library. Export in 1080p.

![Edit in YouTube Create — YouTube Create app → Timeline](/images/guides/faceless-youtube-shorts-with-free-ai-script-to-upload/step-4.svg)

### Step 5: Title, description and upload

Upload from the YouTube app as a Short. Use Gemini to write the title and description.

![Title, description and upload — Write 5 YouTube Shorts titles under 60 characters, and a 2-line description → Published](/images/guides/faceless-youtube-shorts-with-free-ai-script-to-upload/step-5.svg)

**Prompt · step 5**

```text
Write 5 YouTube Shorts titles under 60 characters for this script, and a 2-line description with 3 hashtags. Script: [paste]
```

## Limits, straight talk

- YouTube doesn't monetise mass-produced, repetitive content. Add your own opinion, research or story so each Short is genuinely different.
- ElevenLabs free voices are for personal use — upgrade before monetising.
- Meta AI's Animate feature isn't available everywhere; if you don't have it, use still images with slow zoom in the editor.
- Post in one niche, at a similar time each day, and keep Shorts 30–45 seconds.

Only if each Short is genuinely different. YouTube doesn't monetise mass-produced, repetitive content — add your own opinion, research or story.

### Can I use free AI voices on a monetised channel?

Check the voice tool's terms. Many free plans are for personal use only — upgrade before monetising.

Yes — every tool in this guide works on a phone.
