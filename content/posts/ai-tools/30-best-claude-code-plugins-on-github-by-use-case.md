# 30 best Claude Code plugins on GitHub — pick by use case

Plugins and skills turn Claude Code into a specialist — a senior developer, researcher, designer or video editor. Here's how to choose the right ones by what you want to do, and install them safely.

## What you need

- **Claude Code** — Paid plan.
- **GitHub** — Free account helps to check repos.

## Step by step

### Step 1: Pick your use case

Coding like a senior dev, research, big projects with fewer tokens, design and slides, or video & content. Start with one area only.

![Pick your use case — What do you want?](/images/guides/30-best-claude-code-plugins-on-github-by-use-case/step-1.svg)

### Step 2: Let Claude suggest options

Tell Claude your goal in one line. Ask for 5 well-known options with stars, licence, what each installs and any risks. Official Anthropic skills and plugins are the safest place to start.

![Let Claude suggest options — I want to do this. Suggest 5 well-known Claude Code plugins or skills on GitHub → Options](/images/guides/30-best-claude-code-plugins-on-github-by-use-case/step-2.svg)

**Prompt · step 2**

```text
I want to {goal}. Suggest 5 well-known Claude Code plugins or skills on GitHub for this. For each: what it does, GitHub stars, licence, what it installs, and any risks. Prefer official Anthropic skills first.
```

### Step 3: Read before installing

Before installing, ask Claude to read the plugin's README and install script and explain in simple words if it adds hooks, proxies, shell changes or needs your logins. If it needs your passwords or cookies, skip it.

![Read before installing — Read the README and install script. Does it add hooks, proxies, shell changes? → Check](/images/guides/30-best-claude-code-plugins-on-github-by-use-case/step-3.svg)

**Prompt · step 3**

```text
Read the README and install script of [plugin name]. Does it add hooks, proxies, shell changes, or need my logins/cookies? Explain in simple words.
```

### Step 4: Install one

Install just one plugin and try it on a real task. If it doesn't help in a week, remove it.

![Install one — Install the plugin and show me one example on my files → One plugin](/images/guides/30-best-claude-code-plugins-on-github-by-use-case/step-4.svg)

**Prompt · step 4**

```text
Install [plugin name] and show me one example of using it on my files.
```

### Step 5: Remove what you don't use

Fewer plugins = fewer risks and less confusion.

![Remove what you don't use — List my installed plugins and skills and remove the one I don't use → Why](/images/guides/30-best-claude-code-plugins-on-github-by-use-case/step-5.svg)

**Prompt · step 5**

```text
List my installed plugins and skills and remove [name].
```

## Limits, straight talk

- Plugins run code on your computer; some add hooks, proxies or shell rewriting; NotebookLM-py and a few others need your logins/cookies (terms risk); licences vary (AGPL, unclear, Remotion company limits).
- Stars ≠ safety.
- Advice: install one, read the repo first.

## Questions people ask

### Are GitHub stars a sign it's safe?

No. Stars show popularity, not safety. Always read what a plugin installs before adding it.

### How many plugins should I install?

As few as possible — one or two that you use every week. More plugins mean more risk and confusion.

### Do plugins cost money?

Most are free, but Claude Code itself needs a paid plan, and some plugins call paid services.
