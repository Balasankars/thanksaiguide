## What you need

- **Claude Code** — Paid plan.
- **motion-design-skills** — Free on GitHub.

## Step by step

### Step 1: Install

Ask Claude Code to install the pack from GitHub and list the 5 styles. Ask what it installs before saying yes.

![Install — Install the motion-design-skills pack and list the 5 styles → Styles](/images/guides/motion-design-skills-5-animation-styles-as-claude-skills/step-1.svg)

**Prompt · step 1**

```text
Install the motion-design-skills pack from GitHub and list the 5 styles it adds.
```

### Step 2: System diagram

The system-diagram style animates boxes and arrows — great for explaining how something works. Describe the process in simple steps.

![System diagram — Use the system-diagram style to animate my idea. 15 seconds, vertical → System diagram](/images/guides/motion-design-skills-5-animation-styles-as-claude-skills/step-2.svg)

**Prompt · step 2**

```text
Use the system-diagram style to animate: {idea}. 15 seconds, vertical.
```

### Step 3: Data chart

Give your real numbers and the data-chart style grows a bar chart one bar at a time. Only use numbers you can back up.

![Data chart — Use the data-chart style to animate a bar chart of my numbers → phone showing YOUR NUMBERS bar by bar](/images/guides/motion-design-skills-5-animation-styles-as-claude-skills/step-3.svg)

**Prompt · step 3**

```text
Use the data-chart style to animate a bar chart of [your numbers], growing one bar at a time.
```

### Step 4: 3D toy

The 3D-toy style shows your idea with cute toy-like characters. Good for light, fun topics.

![3D toy — Use the 3D-toy style to show my idea with toy-like characters → phone showing 3D TOY characters](/images/guides/motion-design-skills-5-animation-styles-as-claude-skills/step-4.svg)

**Prompt · step 4**

```text
Use the 3D-toy style to show {idea} with toy-like characters.
```

### Step 5: Test quality

The pack is new, so make the same idea in two styles and keep the one that looks best. Don't promise followers a quality you haven't tested.

![Test quality — Same idea → The pack is new](/images/guides/motion-design-skills-5-animation-styles-as-claude-skills/step-5.svg)

**Prompt · step 5**

```text
Make the same idea in kinetic-typography and hand-drawn styles so I can compare.
```
