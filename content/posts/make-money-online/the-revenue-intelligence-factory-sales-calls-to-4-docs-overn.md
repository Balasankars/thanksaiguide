# Sales calls → case study, landing page and follow-up overnight

A call notetaker records your sales calls; a Claude skill reads each transcript on a schedule and creates a landing page, case study, short white paper and deck in the client's own words, plus a follow-up email saved to your drafts. You review and send.

## What you need

- **A notetaker with a Claude connector** — e.g. Fathom.
- **Claude** — Paid plan with skills and scheduled tasks.
- **Gmail connector** — For drafts.

## Step by step

### Step 1: Connect the notetaker

Add your call notetaker's connector in Claude's settings. Always tell clients the call is being recorded and get their OK.

![Connect the notetaker — Notetaker connector → Always](/images/guides/the-revenue-intelligence-factory-sales-calls-to-4-docs-overn/step-1.svg)

### Step 2: Create the skill

Ask Claude to create a skill that turns one call transcript into a landing page draft, a case study, a short white paper, a 6-slide deck and a follow-up email — all in the client's own words.

![Create the skill — Create a skill: read a sales call transcript and produce 3 things → From one call](/images/guides/the-revenue-intelligence-factory-sales-calls-to-4-docs-overn/step-2.svg)

**Prompt · step 2**

```text
Create a skill: read a sales call transcript and produce 1) a landing page draft, 2) a case study, 3) a 2-page white paper, 4) a 6-slide deck — all using the client's own words — and 5) a follow-up email draft. For {biz}.
```

### Step 3: Test on one call

Run the skill on your latest call and read everything it made. Fix the skill's instructions until the output is good enough to use with light edits.

![Test on one call — Run the skill on my latest call and show me everything → Check the quality](/images/guides/the-revenue-intelligence-factory-sales-calls-to-4-docs-overn/step-3.svg)

**Prompt · step 3**

```text
Run the skill on my latest call and show me everything.
```

### Step 4: Schedule

Schedule the skill to run every night on new calls and save follow-ups as Gmail drafts. Scheduled tasks run only while your computer is awake with Claude open.

![Schedule — Run this skill every night on new calls and save the follow-up as a Gmail draft → Needs](/images/guides/the-revenue-intelligence-factory-sales-calls-to-4-docs-overn/step-4.svg)

**Prompt · step 4**

```text
Run this skill every night on new calls and save the follow-up as a Gmail draft.
```

### Step 5: Review and send

Read every draft before it goes out. Check that numbers and quotes really match what the client said.

![Review and send — Gmail drafts → You](/images/guides/the-revenue-intelligence-factory-sales-calls-to-4-docs-overn/step-5.svg)

## Limits, straight talk

- Pieces are real: Fathom has an MCP, Claude supports skills and scheduled tasks.
- Scheduled tasks run only while your computer is awake with Claude open.
- Ask clients before recording calls.

## Questions people ask

### Is recording sales calls allowed?

Only with the client's consent. Tell them at the start of the call.

### Which notetakers work?

Any notetaker with a Claude connector, for example Fathom.

### Does it send emails by itself?

No. Follow-ups are saved as drafts for you to review and send.
