## What you need

- **Claude** — Skills work in the Claude app. Video editing needs Claude Code (desktop app Code tab) — paid Pro plan or above.
- **YouTube Agent Skill pack** — Free, open source on GitHub — /yt-script, /yt-package, /yt-edit, /yt-seo and more.
- **Video Use (editing skill)** — Free code. Needs FFmpeg + an ElevenLabs API key for word timings (free tier, then paid).
- **Laptop + phone/camera** — Laptop for setup and editing, phone or screen recorder to record your video.

## Limits, straight talk

- AI వాడినంత మాత్రాన monetization రాదు. YouTube 'inauthentic content' policy (July 2025 నుండి) mass-produced, template videos కి money ఇవ్వదు — మీ ideas, example, voice/face ప్రతి video లో ఉండాలి.
- Ad revenue కి ఇప్పుడు 1,000 subscribers + 4,000 watch hours (12 months) లేదా 10M Shorts views (90 days). 1 Feb 2027 నుండి new applicants కి 8,000 watch hours లేదా 20M Shorts views. 500 subscribers దగ్గర fan-funding tier (memberships, Super Thanks) ఉంది.
- Ads కోసం wait చేయకండి: affiliate links, మీ digital products, services Day 1 నుండి start చేయొచ్చు.
- Editing skills కి FFmpeg, Python/Node.js, API keys (ఉదా: ElevenLabs) కావాలి — కొన్ని paid. మీకు సరిపోయే 2–3 మాత్రమే install చేయండి.
- ఇవి community open-source skills — install ముందు Claude తో files check చేయించండి, passwords ఎప్పుడూ paste చేయకండి, upload ముందు ప్రతి video మీరే review చేయండి.
